## 请在本机验收

打开 `build/local-all-chart-readout/FlowGuard.exe`，窗口标题带“图表交互增强”。原 `build/windows-msvc/FlowGuard.exe` 和正在运行的验收版未覆盖。

所有统计曲线、CPU和内存曲线已统一为自动缩放、真实采样点吸附及清晰提示卡；柱状图支持分类区域读取和高亮，零高度柱也可读取；饼图支持扇区高亮及类别、包数、占比提示。定时刷新保持提示。图表单位、统计口径、采集/保存及文件完整分页逻辑不变。新增与既有GUI集成检查通过。

修复离线查看同样淘汰前2000条以外记录的问题。文件读取完成后从第1包显示第1页，支持首页、上一页、下一页、末页、页码跳转；筛选覆盖整个文件。内存只保留当前页，磁盘索引记录各页边界，前面的报文随时能翻回去，不受待显示队列淘汰影响。文件序号从1开始，翻页连续编号；外部修改文件后拒绝沿用旧索引，需重新打开。实时采集仍保留最近2000条。

新增4501包分页专项测试（2000+2000+501、往返翻页、跨页筛选、空文件、截断、取消及文件变更）；GUI测试验证2600包文件按1–2000及2001–2600完整显示。

采集前可用主界面的“选择保存位置…”预选目录。“从采集开始保存”默认勾选，开始即从首包写入；取消勾选则只采集分析，直到点击“保存后续报文”直接向预先生成的路径发出保存请求，不再弹路径窗口。两种方式均在所选目录生成带时间和随机标识的PCAP。停止后文件已保存，可直接“打开已保存 PCAP”，也可“导出 PCAP…”另存副本。显示筛选不影响写盘内容，主界面区分实际保存数与总采集数；中途保存不补存此前报文。每次采集可选择一种保存区间，停止后开始新会话可另存一段。

单次文件最多16 GiB，并按启动时可用空间预留256 MiB；达到上限或写入失败显示错误，不允许把失败结果导出为完整副本。正常数据和失败时的文件均保留，不自动删除；旧版未保留的报文不能补回。

GUI 测试采用真实回环报文：默认全程保存10包，停止后导出、回读计数一致；显示筛选隐藏全部行仍导出全部已保存报文；重复导出不覆盖。另测中途保存：先采集8包但不写盘，点击保存后续且无路径弹窗，再采集2600包；总采集2608包、实际保存2600包、导出回读2600包，界面列表仍最多2000条。

设置保存在程序目录内的 `data/storage.ini`；报文目录用于下一次采集，日志新目录下次启动生效。采集期间锁定目录，点击保存后续直接使用预选路径；另行导出副本时才再次选择目标。无设置时默认日志为 `data/runs`、报文目录为 `data/captures`，当前程序位于 E 盘，因此默认数据也在 E 盘。显式环境变量 `FLOWGUARD_LOG_ROOT` 优先于软件设置；写入失败时显示错误，不自动回退 C 盘。正在运行的旧进程不会热切换路径，请手动正常退出后打开新版。

完整使用方法和20分钟人工验收见 [使用指南](FlowGuard使用指南.html)，也可从新版“帮助 → 使用指南（含20分钟验收）”打开。20分钟由用户亲自操作，本轮不自动启动长测。

1. 打开 `tests/data/stage1-protocols.pcap`，应读取 18 个报文。在统计页面检查顶部协议汇总表，切换显示筛选后确认累计统计不变。
2. 返回报文页面，依次选择 IPv4/TCP、IPv6/UDP 报文并展开详情树。确认序列号、确认号、窗口、长度、校验和、流标签等对应字段显示正常。
3. 如发现排版问题，请提供统计表和展开报文详情树两张截图，标明所在页面和操作步骤。

本轮自动测试采用 offscreen 平台，实际 Windows 字体、缩放与布局还需要以上人工确认。验收通过后再决定提交与推送。
