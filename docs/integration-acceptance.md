## 人工验收与限制

1. 按 README 的开发运行环境启动本目录的新 FlowGuard.exe。查看“保存设置”和“帮助 → 使用指南”。日志默认在该 exe 旁的 data/runs，PCAP 默认桌面目录独立设置。
2. 导入 alerts-demo.pcap（2082 包），确认 5 类预警；SYN 阈值 500→1000 撤警，1000→100 恢复。文件报文页翻到末页，应能看到第 2001–2082 包；切页不改变预警和累计统计。
3. 打开 stage1-protocols.pcap，核对完整字段树和协议汇总表；悬停统计图、资源曲线查看读数。
4. 准备实时采集，提前开启保存；结束后确认名称和位置，再重新导入保存文件。采集中途另起一段、取消最终保存、停止和关闭窗口的行为按保存说明核对。
