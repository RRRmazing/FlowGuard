## 用户验收

1. VS Code 打开内层目录，在终端执行 `.\scripts\build.cmd`，确认成功。
2. 执行 `.\scripts\run.cmd`，确认“流量哨兵”窗口、中文及 Npcap 版本文字正常。
3. 关闭窗口，执行 `.\scripts\test.cmd`，确认 `100% tests passed`。
4. 将结果反馈当前聊天；确认通过后保存首次提交和 `stage-0` 标签，再进入阶段 1。
