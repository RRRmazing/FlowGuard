## 范围与限制

- 回环 DLT=0 的解析按合同返回 Unsupported；此流量验证 Qt 采集/停止/保存，不冒充真实 Ethernet 字段验证。
- 本轮未执行 4–8 小时稳定性测试、跨天测试或至少 24 小时正式连续运行；没有真实人工正常使用观察，最终性能结论尚未完成。
- 日志目录创建失败已测试，没有实际填满磁盘。保存最大 1 GiB，当前不自动轮转；正式长测前需确认保存策略。
- UI 列表最多 2000 条，屏幕曲线最多 3600 点；全天资源 CSV 独立持续记录，最终图表从完整日志生成。
