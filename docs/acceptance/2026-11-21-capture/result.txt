环境

验证方法
1. 在 MSVC x64 开发环境中运行标准 CMake 配置与构建：
   cmake --preset windows-msvc
   cmake --build --preset windows-msvc
   （本机已在缓存中配置 Qt、Ninja、SDK 路径；新机器按根 README 配置。）
2. 准备当前终端的 Qt、Npcap DLL 与 Qt 平台插件路径后运行 CTest：
   ctest --test-dir build/windows-msvc --output-on-failure --no-tests=error
   本轮回归将 QT_QPA_PLATFORM 临时设为 offscreen，不在桌面弹出 Qt 窗口；
   该结果验证依赖和事件循环，不替代人工中文显示检查。
3. 只验证采集测试可使用 -R "^capture_"，无需 Qt DLL 和平台插件。
4. 设置 Npcap DLL 路径后运行：
   .\build\windows-msvc\flowguard_capture_probe.exe --list-devices
