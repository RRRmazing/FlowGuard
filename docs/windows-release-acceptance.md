# Windows v0.1.0 发布验收

2026-11-22，Windows x64 / MSVC 14.51.36231 / Qt 6.11.0 / Inno Setup 7.1.1。

## 实现

- 主程序延迟加载 wpcap.dll，启动时从 Windows 系统 Npcap 子目录加载，缺失时显示提示。
- 当前用户安装、中英文界面、可选桌面快捷方式、独立安装路径与数据路径。
- 无现有配置时提供报文、日志目录页面，UTF-8 INI 保存到本地用户应用数据目录。存在配置时跳过页面并保留原文件。
- 微软官方签名 VC++ x64 Redistributable 14.51.36247 随包提供；按当前工具链版本检测，仅在需要时提权安装。Npcap 不捆绑，缺失时明确提示。
- 项目 GPL-3.0-only 许可证、依赖说明、Qt 许可证及源代码版权通知、相关 SPDX SBOM 随包提供。

## 验证

- CMake Release 配置和构建成功；正常权限环境完整 CTest 24/24，通过时间约 22 秒，含硬件测试。
- 首轮沙箱内测试受 Npcap 管理员模式和临时目录限制，不作为发布通过证据；沙箱外完整复核通过。
- Inno Setup 脚本编译成功；安装返回 0。
- 安装后的 FlowGuard 在 PATH 仅含 Windows 系统目录且无 Qt 插件环境变量时，`--smoke-test` 和真实固定 PCAP 的 `--accept-file` 均返回 0。
- 同版本重新安装返回 0。安装前后 storage.ini SHA-256 相同。
- 卸载测试副本，检查主程序删除以及原配置保留；见本机 build 下发布验证日志。

## 限制与人工检查

本机已安装 Qt 开发环境、Npcap 和 VC++ 运行库，因此不能替代干净电脑验收。尚未在无配置的新 Windows 用户下完整验收目录页面和首次配置写入，也未实际触发缺失 VC++ 运行库的管理员安装分支。数据目录在安装准备阶段创建；取消可能保留空目录。目录可写性与可用空间还会由应用再次校验。未验证 Windows on ARM、证书签名以及至少 24 小时稳定性。

人工检查时，在 x64 Windows 测试机先安装 Npcap，运行 Release 安装包；选择中文目录，检查程序保存设置与所选一致，打开固定 PCAP，再测试抓包、重装保留设置和卸载保留报文。公开 Release 标为预发布，以这些实际验证范围为准。
